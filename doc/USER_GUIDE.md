# 사용자 가이드 (USER GUIDE)

> 코드 없이 3D 공간과 게임을 만들어 웹에 배포하는 에디터의 사용 설명서입니다.
> 처음 쓰는 분은 **1 → 3 → 4 → 9 → 11** 순서로 따라 하면 첫 작품을 게시할 수 있습니다.
> (작성 기준: 2026-07-15)

---

## 1. 시작하기

1. 사이트 접속 → **로그인**(첫 화면이 로그인 페이지입니다).
2. **대시보드**에서 `새 프로젝트` 카드를 클릭해 프로젝트를 만듭니다.
3. 프로젝트 카드를 클릭하면 **에디터**가 열립니다.
4. 씬을 추가할 때는 **템플릿**(빈 씬/쇼룸/갤러리/광장/카페)을 고를 수 있습니다.

> 💡 하나의 **프로젝트** 안에 여러 **씬**(공간)을 만들 수 있고, 씬끼리 이동하는 게임/사이트를 만들 수 있습니다.

---

## 2. 에디터 화면 구성

```
┌────────────────────────────────────────────────┐
│  상단 바:  ← 대시보드 | 저장 | 버전 기록 | 미리보기 | ▶ 플레이  │
├──────┬─────────────────────────────┬───────────┤
│ 레일  │                             │           │
│ (탭)  │        3D 뷰포트            │  인스펙터  │
│      │   (하단: 떠있는 툴바)         │ (속성 패널) │
│ 좌패널│                             │           │
└──────┴─────────────────────────────┴───────────┘
```

- **레일/좌패널**: 오브젝트 목록(계층), 에셋 브라우저, **Logic 탭**(게임 변수·전역 규칙·HUD), 씬 전환.
- **뷰포트 하단 툴바**: 도형 추가, 펜 툴, 복셀, ✨프리셋, 이동/회전/크기 모드, 스냅, 정렬, 격자 평면.
- **인스펙터**(오른쪽): 선택한 오브젝트의 위치·재질·물리·이벤트·애니메이션 등 모든 속성.
- **빈 곳을 클릭**(선택 해제)하면 인스펙터가 **환경 설정**(조명·하늘·안개·바닥·경계 등)으로 바뀝니다.

## 3. 카메라 조작 & 기본 단축키

| 동작 | 방법 |
|---|---|
| 화면 회전 | **Ctrl + 왼쪽 드래그** |
| 화면 이동(패닝) | **오른쪽 드래그** |
| 확대/축소 | **마우스 휠** |
| 여러 개 선택 | 왼쪽 드래그(박스 선택) 또는 Shift+클릭 |
| 그룹 안 자식 선택 | 같은 오브젝트를 **더블클릭** |
| 선택한 것으로 화면 맞춤 | **F** |
| 전체가 보이게 맞춤 | **Shift + F** |
| 위/정면/측면 뷰 | 숫자패드 **7 / 1 / 3** |

**편집 단축키**

| 키 | 기능 |

| W / E / R | 이동 / 회전 / 크기 기즈모 전환 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+D | 복제 (Shift+D = 제자리 복제) |
| Ctrl+G / Ctrl+Shift+G | 그룹 만들기 / 그룹 해제 |
| Ctrl+Shift+C / V | 속성 복사 / 붙여넣기 |

| Ctrl+S | 저장 |

| Esc | 배치 취소 / 모달 닫기 |

## 4. 오브젝트 만들기

### 4-1. 기본 도형
하단 툴바의 **도형 버튼**을 클릭 → 뷰포트에서 원하는 위치를 클릭하면 그 자리에 생성됩니다(Esc로 취소). 화살표(▾)를 누르면 상자·구체·원기둥·원뿔·각뿔대·로프트 등 목록이 열립니다.

### 4-2. ✨ 프리셋 (완성형 재료)
툴바의 ✨ 버튼 → **바퀴**(굴러감), **문**(E키로 통과), **동전**(먹으면 점수+1) 등 동작이 미리 설정된 오브젝트를 바로 배치할 수 있습니다.

### 4-3. 펜 툴 (직접 그려서 만들기)
툴바의 ✏ 버튼 → 2D 캔버스에 점을 찍어 도형을 그립니다.
- **돌출**: 그린 단면을 두께만큼 밀어 기둥 형태로.
- **회전체**: 그린 옆선을 360° 돌려 컵·병·도자기 형태로.
- 첫 점을 다시 클릭하면 닫힘, Ctrl+클릭으로 선 위에 점 추가, 스무딩으로 곡선화.
- 만든 오브젝트는 나중에 **오브젝트 목록 우클릭 → "펜툴로 수정"**으로 다시 고칠 수 있습니다.

### 4-4. 복셀 (큐브 쌓기)
툴바의 복셀 버튼 → 마인크래프트처럼 층별로 색 큐브를 칠해 만듭니다.
- 좌클릭 칠하기 / 우클릭 지우기, 층(Y) 이동으로 쌓기, 3D 미리보기 제공.
- 우클릭 → **"복셀 수정"**으로 언제든 재편집.

### 4-5. 3D 모델(GLB) 업로드
좌패널 **에셋 브라우저 → Models 탭**에서 `.glb` 파일 업로드 → 클릭해 배치. 추가하면 밑면이 자동으로 바닥에 맞춰집니다.

### 4-6. 합치기 / 구멍 뚫기 (Boolean)
여러 도형 선택 → 인스펙터의 **합치기**(하나의 오브젝트로 병합) 또는 2개 선택 시 **Boolean**(합집합/빼기/교집합)으로 구멍 뚫린 형태 등을 만듭니다. 되돌리려면 Ctrl+Z.

## 5. 꾸미기 (재질·텍스처·조명)

- **색/재질**: 오브젝트 선택 → 인스펙터 **Material** 섹션에서 색·거칠기·금속성·발광 조절. 유리(투과)·코팅 같은 고급 물리 재질도 지원.
- **텍스처(이미지 입히기)**: Material의 Texture 스위치를 켜고 이미지를 업로드하거나, 에셋 브라우저 **Textures 탭**에서 선택 적용. 타일 반복 횟수 조절 가능.
- **재질 공유(스타일)**: "이 재질을 에셋으로 저장" → 여러 오브젝트에 적용 → 라이브러리에서 한 번 수정하면 전부 반영.
- **조명**: 에셋 브라우저에서 라이트(포인트/스팟/방향광) 추가. 스팟/방향광은 뷰포트에서 **끝 핸들을 드래그**해 방향과 길이를 조절.
- **분위기**: 빈 곳 클릭 → 환경 패널의 **Mood 프리셋**(아침/한낮/노을/밤/스튜디오) 또는 에셋 브라우저 **HDR 탭**에서 배경 환경 선택.

## 6. 상호작용 만들기 (이벤트)

오브젝트 선택 → 인스펙터 **Events** 섹션 → `+ 이벤트 추가`.

**"언제(트리거) → 무엇을(액션)"** 형식으로 만듭니다.

| 트리거 예시 | 설명 |
|---|---|
| 클릭 / 호버 | 마우스로 누르거나 올렸을 때 |
| Interact (E) | 플레이 모드에서 다가가 E키를 눌렀을 때 |
| 다가가면 (approach) | 캐릭터가 가까이 오면 자동 발동 |
| 영역 진입/이탈 (area) | 센서 영역을 통과할 때 |

| 액션 예시 | 설명 |
|---|---|
| 팝업 표시 | 이미지/영상/웹페이지/직접 쓴 HTML을 팝업으로 |
| 씬 이동 | 다른 씬(방)으로 이동 |
| 오브젝트 표시/숨김/이동 | 다른 오브젝트 조작 |
| 문 열기 (통과 가능) | 콜라이더를 꺼서 지나갈 수 있게 |
| 소리 재생 / 애니 재생 | 사운드, 애니메이션 클립 |
| 변수 변경 | 점수 올리기 등 (7장 참고) |

- **조건**을 붙이면 "점수가 3 이상일 때만" 같은 규칙이 됩니다(AND/OR, 아니면-else도 가능).
- **대화 말풍선**: Events 섹션 상단에서 NPC 대사(여러 줄, 타이핑 효과, 화자 이름)를 설정할 수 있습니다.

## 7. 게임 만들기 (변수·HUD·승패)

왼쪽 레일의 **Logic 탭**이 게임 로직의 홈입니다.

1. **게임 변수**: `score`(숫자), `hasKey`(참/거짓), `state`(상태 목록), `timer`(초 카운트다운) 등을 만듭니다. **유지 범위**를 설정하면 씬을 이동해도(global) 또는 재접속해도(persistent, 최고점수용) 값이 유지됩니다.
2. **HUD (화면 표시)**: 변수를 화면 구석에 텍스트·게이지바·하트(목숨)로 표시.
3. **전역 규칙**: 특정 오브젝트가 아닌 씬 전체 규칙 — 예) `게임 시작 시 → 타이머 시작`, `score ≥ 3 → 문 열기`, `timer ≤ 0 → 패배`.
4. **승패**: `game_win` / `game_lose` 액션 → 결과 화면 + 다시 시작 버튼이 자동 표시됩니다.

**예제: 동전 3개 모으면 문이 열리는 게임**
1. ✨프리셋으로 동전 3개 배치 (자동으로 `score` 변수와 "먹으면 +1" 이벤트가 생깁니다)
2. 문 오브젝트에 이벤트: 트리거 `변수가 바뀔 때` + 조건 `score ≥ 3` → 액션 `통과 가능`
3. ▶ 플레이로 테스트!

## 8. 애니메이션 만들기

오브젝트 선택 → 인스펙터 **Animation** 섹션.

### 간단 모드 (처음 쓸 때 추천)
1. `클립 만들기` → 현재 상태가 시작 포즈로 저장됩니다.
2. 오브젝트를 옮기고/돌리고 → `포즈 추가` 반복.
3. 포즈를 클릭한 상태에서 오브젝트를 움직이면 **그 포즈가 자동 수정**됩니다(오토키).
4. ▶ 미리보기로 확인 → Events에서 `트리거 → 애니 재생(play_clip)` 연결.

### 타임라인 모드 (정밀 편집)
Animation 헤더에서 모드를 전환하면 **화면 하단에 타임라인 패널**이 열립니다.
- **휠 = 줌**, 눈금자 드래그 = 좌우 이동, ◆(키프레임) 클릭 = 그 포즈로 이동, ◆ 드래그 = 시간 변경, ◆ 선택 후 Del = 삭제.
- 눈금자/레인 **우클릭 → "여기에 키프레임 추가"**.
- 한 클립에 **여러 오브젝트(트랙)**를 담아 함께 움직일 수 있고(양문 등), 트랙마다 키를 **서로 다른 시간**에 배치할 수 있습니다.
- **이징(속도 곡선)** 6종을 클립 기본 또는 구간별로 선택.

### 회전축(경첩)
문처럼 **모서리를 축으로** 돌게 하려면 Animation 섹션의 '회전축(경첩)'에서 좌/우/앞/뒤 모서리를 선택하세요.

## 9. 플레이 테스트

- 상단 바의 **▶ 플레이** 버튼 → 편집 중인 씬에서 바로 캐릭터로 걸어다니며 테스트. **■ 편집으로** 버튼으로 복귀.
- **조작**: WASD 이동, 드래그로 시점 회전, **E** 상호작용, **F** 물건 차기(넉백).
- 물리: 인스펙터 **Physics**에서 Dynamic을 켜면 중력으로 떨어지고 밀 수 있는 물체가 됩니다.

## 10. 저장·씬·버전

- **저장**: Ctrl+S 또는 상단 Save 버튼. (저장 안 된 변경이 있으면 상단에 표시됩니다.)
- **씬 관리**: 좌측 씬 전환 메뉴에서 씬 추가(템플릿 선택)·이름 변경·기본 씬 지정.
- **버전 기록**: 상단 시계 아이콘 → 이전 저장 시점으로 복원 가능.
- **프로젝트 복제**: 대시보드 카드의 `···` 메뉴 → 복제(에셋 포함 완전 독립 사본).

---

## 11. 게시와 공유

1. **공개 전환**: 대시보드 프로젝트 카드에서 공개로 전환합니다(비공개면 다른 사람이 볼 수 없습니다).
2. **링크 공유**: 카드의 공유 버튼 → 뷰어 링크 복사.
3. **내 웹사이트에 임베드**: 공유 모달의 임베드 탭에서 코드 복사.
   - **스크립트 방식(권장)**: `<script src=".../embed.js" data-scene="...">` 한 줄.
   - **iframe 방식**: 일반 `<iframe>` 태그.
4. **커스텀 도메인**: 카드 메뉴에서 내 도메인 연결(DNS 설정 필요).

**뷰어 모드 설정** (빈 곳 클릭 → 환경 패널):
- **기본 진입 모드**: 둘러보기(탐색) 또는 걷기(플레이) 중 선택.
- **걷기 모드 사용** 토글을 끄면 둘러보기 전용 공간이 됩니다.
- **화면 비율(Frame)**: 16:9 등으로 고정하면 뷰어가 레터박스로 표시됩니다.

## 12. 자주 묻는 질문 / 팁

**Q. 오브젝트가 바닥에 파묻혔어요.**
→ 인스펙터 Transform의 **⤓ 바닥에 놓기** 버튼을 누르세요.

**Q. 뒤로 회전/이동을 잘못했어요.**
→ Ctrl+Z. 거의 모든 동작이 취소됩니다.

**Q. 여러 개를 한꺼번에 정렬/복제하고 싶어요.**
→ 여러 개 선택 후 인스펙터에서 정렬·간격 배치, 또는 **Array 섹션**에서 일정 간격 N개 복제.

**Q. 방문자에게 클릭 가능한 오브젝트를 알려주고 싶어요.**
→ 클릭/호버 이벤트가 있는 오브젝트에는 뷰어에서 자동으로 **힌트 링**이 표시됩니다(환경 패널에서 끄기 가능).

**Q. 팝업에 우리 회사 웹페이지를 띄우고 싶어요.**
→ 팝업 액션에서 모드를 **URL**로 하고 주소 입력. 직접 쓴 HTML도 가능합니다.

**Q. 임베드한 3D에서 클릭하면 우리 사이트의 페이지가 열리게 하고 싶어요.**
→ 액션을 `emit_event`로 하면 호스트 페이지가 `park3d:event`를 받아 원하는 동작을 할 수 있습니다(개발자 연동 필요).

**Q. 저장을 깜빡할까 걱정돼요.**
→ 현재는 수동 저장(Ctrl+S)만 지원합니다. 작업 중 수시로 저장하세요.
